# Application repository agent entry point

Before every task, read and follow **`../AGENTS.md`**, then read **`../project context.md`** and **`../memory.md`** in full. Resolve these paths relative to this file, even if the current directory differs.

The parent files contain the canonical assignment rules, grading gates, task workflow, and shared memory. Checkpoint meaningful progress and update `../memory.md` before every final response or handoff, as directed by the parent instructions. Do not create a separate application-level memory or duplicate requirement record.

If this repository was copied without its parent records, report the missing files and obtain/recover the actual records and assignment source before claiming to have loaded project context. Include the parent records and source PDF when handing off the project.
